사용 방법
💾
코드 업로드
각 실험 페이지에서 제공하는 마이크로비트 코드를 MakeCode에서 불러와 마이크로비트에 저장합니다.
🔌
USB 연결
마이크로비트를 USB로 PC에 연결한 뒤 Chrome에서 [포트 연결]을 클릭합니다.
▶
측정 시작
마이크로비트의 A 버튼을 누르거나 페이지에서 [측정 시작]을 클릭합니다.
📊
실시간 그래프
데이터가 자동으로 그래프와 표에 표시됩니다. 슬라이딩·누적 모드를 선택할 수 있습니다.
💾
CSV 저장
측정 완료 후 [CSV 다운로드]로 Excel에서 바로 열 수 있는 파일을 저장합니다.
micro:bit V2 · Web Serial API · Chrome 89+
